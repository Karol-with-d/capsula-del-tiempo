# Cápsula del Tiempo

Es una aplicación para escribir mensajes a tu yo del futuro. Cada cápsula tiene un título, un mensaje, una emoción y una fecha de apertura. El mensaje solo se puede leer cuando llega esa fecha.

Proyecto en línea: https://capsula-del-tiempo-one.vercel.app/

## Qué se puede hacer
- Crear, ver, editar y eliminar cápsulas
- Filtrar por emoción, incluyendo la opción Otro
- Los datos se quedan guardados en el navegador aunque recargues la página
- Diseño de cartas antiguas, con vela, tintero para recargar tinta cada ciertos caracteres, letra a mano y sellos de cera

## Tecnologías
- Vite + TypeScript
- sql.js (SQLite en el navegador) y localStorage
- Arquitectura MVC (modelo, vista y controlador)

## Cómo ejecutarlo
```
npm install
npm run dev
```
Después abre en el navegador la dirección que aparece en la terminal.
